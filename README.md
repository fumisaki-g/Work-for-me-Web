# Student Dashboard
เปิดใช้งานได้ทันทีโดยดับเบิลคลิก index.html (โหมดทดลอง เก็บข้อมูลในเบราว์เซอร์) แต่ควรรันผ่านเซิร์ฟเวอร์ เช่น `npx serve` หรือ VS Code Live Server

## เชื่อม Supabase
1. สร้างโปรเจกต์ที่ supabase.com แล้วเปิด SQL Editor
2. วางและรัน `supabase_schema.sql`
3. Project Settings > API คัดลอก Project URL และ anon public key ใส่ใน `js/config.js`

### รูปตารางเรียน
ในเมนู “ตารางเรียน” เลือกไฟล์ JPG, PNG หรือ WebP ขนาดไม่เกิน 10 MB รูปจะถูกบันทึกใน Supabase Storage และเปิดดูได้จากอุปกรณ์อื่น เมื่อเชื่อม Supabase แล้วให้รัน `supabase_schema.sql` อีกครั้งเพื่อสร้าง bucket และสิทธิ์จัดการรูป หากใช้โหมดทดลอง รูปจะเก็บใน IndexedDB ของเบราว์เซอร์นั้นเท่านั้น

## เชื่อม Google Sheet (การเงิน)
1. สร้างชีต แถวแรกเป็นหัวตาราง (เช่น วันที่ | รายการ | รับ | จ่าย | คงเหลือ)
2. ไฟล์ > แชร์ > เผยแพร่ไปยังเว็บ > เลือกแท็บ > รูปแบบ CSV > คัดลอกลิงก์ใส่ `SHEET_CSV_URL`
3. หน้านี้แสดงผลแบบอ่านอย่างเดียว การแก้ไขทำในชีตผ่านปุ่ม "เปิด Google Sheet"

## ข่าวประชาสัมพันธ์
ใส่ URL ที่ตอบ JSON รูปแบบ `[{"title":"..","date":"2026-10-18","url":"..","summary":".."}]` ใน `NEWS_API_URL` (เซิร์ฟเวอร์ปลายทางต้องเปิด CORS)

## ความปลอดภัย
anon key อยู่ในโค้ดฝั่งเบราว์เซอร์ และนโยบายใน SQL ให้ใครก็ตามที่มีคีย์อ่านเขียนได้ รวมถึงการแทนที่หรือลบรูปตารางเรียน จึงไม่ควรเก็บข้อมูลอ่อนไหวหรือแชร์ลิงก์เว็บสาธารณะ หากต้องการใช้จริงควรเพิ่ม Supabase Auth แล้วเปลี่ยนนโยบายเป็น `to authenticated`

## แสดงเพจ Facebook โรงเรียน
ใส่ลิงก์เพจสาธารณะใน `FB_PAGE_URL` (js/config.js) เว็บจะฝังเพจและโหลดใหม่ทุก 60 วินาที ควรเปิดผ่านเซิร์ฟเวอร์ (`npx serve`) ไม่ใช่เปิดไฟล์ตรงๆ
